Daily Health Brief — Prompt Pack
================================

Four prompts, used in sequence, that built a Claude Code health dashboard
project:

  01-claude-md-starter.txt      — starter CLAUDE.md for the project
  02-dashboard-build.txt        — initial dashboard build
  03-hevy-integration.txt       — Hevy workout data integration
  04-dashboard-redesign.txt     — full visual redesign

Each file is ready to paste as-is.

A tip before you use these: you don't need to know your exact file paths
up front. The health-export folder path in prompts 02-04 is just a
starting placeholder — nobody has their export folder path memorized.
Claude will locate your actual files, confirm the real folder and
filename pattern, and adjust automatically. That's the workflow working
as intended: start with a reasonable guess, let Claude verify it against
your real files.

Prompt 04 has placeholders like [Your Name], [Your tagline], and
[Weight: X kg] — fill those in with your own details before using it.
